# Hole blueprint provenance and privacy (ZK-652)

Saved templates retain source kind, source label, import time, explicit rights attestation, optional license and credit, redistribution policy, the source-retention decision, and fidelity evidence. No source pixels enter template packages or placed holes. Source retention is recorded as `sourceAssetRetained: false`; requesting retained pixels is rejected. Rejected blueprint imports retain a diagnostic receipt rather than the untrusted image-bearing input.

`Sketch` means an approximate layout. Every capture starts at Sketch, regardless of confidence scores. Historical V1 packages without `fidelity` resolve to Sketch at use time. The field remains absent when canonicalizing or importing those packages, preserving their original checksum. `Calibrated` requires an explicit review of at least two control points and positive verified yardage. Confidence scores, license names, source kinds, and provenance timestamps never infer reviewed accuracy. Surveyed and Licensed are reserved fidelity tiers and rejected by the current validator.

Player photos and unknown-rights templates are private-only. Missing or contradictory claims fail closed. External redistribution requires attested rights and a nonempty license name; attribution and share-alike policies require credit, and share-alike requires a named license. `exportContentPackage(id, platform, "private_copy")` keeps private-copy backup/import usable. Callers explicitly requesting `"redistribution"` are checked before the file picker is invoked. The Library labels template export as a private copy. Private export does not grant redistribution permission.

Placement retains bounded source and rights metadata in `Hole.templateAttribution`, plus resolved fidelity; it retains credit text only when the redistribution policy requires credit. The full blueprint, image pixels, confidence evidence, and placement plan stay outside the placed hole. Historical placed credits remain readable with no implied redistribution rights. Course exports also check these fields when redistribution is requested. Workshop publication is blocked before calling the provider for all template packages and course packages containing placed template provenance. Manually authored courses without template provenance retain their existing Workshop flow.

Recapturing a placed imported hole preserves its original provenance rather than relabeling it as manual or replacing its rights with the new capture claim. Capture resets fidelity to Sketch because the editable hole's original calibration is not reverified. Historical placed holes lacking the full rights metadata require original-source review before recapture.

Only use sources you have permission to use. Official branding or the presence of a course map does not establish a reuse grant. Do not scrape course sites or map providers; use permitted sources and record their license and required credit. The UI includes these instructions and requires a player attestation before local capture.

## Integration boundary

`holeTemplateUsePolicy(untrustedProvenance, "analysis")` is the reusable pre-analysis guard. It validates the complete metadata and requires rights attestation before returning `allowed: true`. **There is no ImportStudio or external image-analysis service enforcement added by this packet.** Those integrations must call this guard before reading/sending pixels or beginning analysis, discard source pixels before saving a validated template, and supply reviewed evidence only after a real control-point and yardage review. These helpers and unit tests do not prove an absent service has enforced them. ZK-652 still requires that integration and any mandated human review before full issue completion.
