# M19 asset provenance

All M19 parkland terrain pixels are original CourseCraft work generated by
`scripts/gen-terrain-materials.mjs`. The script uses only geometric diamond
masks, the palette documented in `ART_GUIDE.md`, deterministic integer noise,
and authored rules for mowing, sand grain, gravel, depth bands, edges, and
corners. No external image, model output, copyrighted game asset, tracing, or
reference-pixel sampling is used.

The three screenshots attached to Linear ZK-212 were treated only as broad
composition references: course-surface density, the relationship between
water and maintained turf, and readable landmark spacing. They were not
downloaded into the repository or used as pixel/color sources.

Review/cleanup is reproducible: run `npm run gen:terrain && npm run build:atlas`,
then inspect `?m19Fixture=1` at the fixed bookmarks and all four rotations.
Generated sources have transparent alpha outside the 128×64 diamond, exact
logical anchors, restrained stepped values, and typed frame names.
