# M28 external playtest protocol

Use the exact deployed `1.0.0-rc.3` URL and a clean browser profile for every
session. Recruit 5–10 people who have not played or watched this build. Record
only a participant code and the minimum useful observations; do not retain
names, contact details, recordings, or verbatim personal information here.

## Moderator script

1. Ask the participant to launch the supplied URL without explaining controls.
2. Observe new-game choice, tutorial completion or skip, first valid hole,
   first open course, and first profitable week. Intervene only if blocked and
   record the exact intervention.
3. Record elapsed time for each milestone, misclicks, help/Golfopedia use,
   confusion, abandonment points, and concise paraphrased reactions.
4. Ask: What felt clear? What was confusing? What was fun or slow? Was the
   course readable? Was audio helpful? Would you continue playing, and why?
